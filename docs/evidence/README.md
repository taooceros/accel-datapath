# Evidence maps

This directory stores current-truth maps, one file per research thread.

Use an evidence map when old reports are scattered and the current answer needs one stable entry point.

Template:

```md
# Thread name

## Current conclusion

## Strongest evidence

## Superseded or caution notes

## Next reproducible action
```

Keep raw history in `archive/docs/`. Link the strongest reports or newly created reports instead of copying raw data.
