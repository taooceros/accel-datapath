# Make hw-eval use idxd-rust raw wrappers

## Goal

Remove the duplicate DSA descriptor/completion wrapper code from `hw-eval` and use the canonical raw Rust wrappers in `idxd-rust`.

## Scope

- Expose `idxd-rust::raw` publicly as the raw wrapper module.
- Expose the DSA raw descriptor pointer helper needed by `hw-eval`'s local portal submission path.
- Refactor `hw-eval/src/dsa.rs` into a compatibility shim over `idxd_rust::raw::dsa`.
- Update DSA benchmark methodology calls to match the canonical raw wrapper method signatures.
- Keep IAX unchanged for now because `idxd-rust` currently exposes only IAX crc64 raw helpers, while `hw-eval` also benchmarks IAX noop latency.

## Verification

- Run `cargo test -p hw-eval --lib --tests`.
- Run formatting and whitespace checks before committing.
