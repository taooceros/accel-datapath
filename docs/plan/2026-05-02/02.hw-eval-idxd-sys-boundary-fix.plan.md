# Fix hw-eval for the new idxd-sys boundary

## Goal

Make `hw-eval` build against the cleaned `idxd-sys` design, where `idxd-sys` exposes raw bindgen UAPI and raw MMIO portal primitives rather than typed descriptor wrappers.

## Scope

- Keep `hw-eval` as the raw hardware benchmark crate.
- Keep local benchmark-facing DSA/IAX descriptor helpers in `hw-eval`.
- Use `idxd_sys::idxd`/`idxd_sys::idxd_uapi` generated UAPI types as the single hardware layout source.
- Do not make `hw-eval` depend on the higher-level `idxd-rust` wrapper crate.

## Intended changes

- Replace the broken DSA re-export shim with local aligned wrappers over bindgen DSA descriptor/completion types.
- Preserve existing `hw_eval::dsa::*` names used by methodology code and tests.
- Use raw-pointer unaligned loads/stores where bindgen fields may be packed.
- Preserve direct descriptor submission through `hw-eval`'s local portal path.

## Verification

- Run `cargo test -p hw-eval --lib --tests` after the compatibility fix.
- If it passes, run `cargo fmt -p hw-eval -- --check` and `git diff --check` before commit.
