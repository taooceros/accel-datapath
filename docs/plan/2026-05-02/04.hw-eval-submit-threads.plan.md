# Add hw-eval submit thread argument

## Goal

Add a simple CLI argument that lets `hw-eval` run a concrete multi-submitter DSA direct memmove benchmark for shared work queues.

## Scope

- Add `--threads <N>` to `hw-eval`, defaulting to 1.
- Keep the existing single-thread benchmark rows unchanged.
- When `--threads > 1`, add DSA direct memmove multi-thread throughput rows using direct descriptors (`batch_n = 1`).
- Keep concurrency as total logical outstanding operations across all submitter threads.
- Avoid generic/static-dispatch benchmark abstractions.

## Verification

- Run `cargo test -p hw-eval --lib --tests`.
- Run formatting/whitespace checks.
- Optionally run a small shared-WQ smoke with `/dev/dsa/wq0.1`.
