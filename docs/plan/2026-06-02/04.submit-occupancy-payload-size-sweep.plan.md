# Submit occupancy payload-size sweep

## Goal

Rerun Experiment 1 TSC-gap pacing with multiple payload sizes: `noop`, 1 MiB, 10 MiB, 100 MiB, and 1 GiB memmove, using 10 iterations.

## Scope

- Keep the previous K cap-320 and TSC-gap sweep shape unless hardware constraints force adjustment.
- Add a submit-occupancy-only shared-payload option if needed to make 100 MiB / 1 GiB payload descriptors feasible without allocating `K * payload_size * 2` bytes.
- Preserve default distinct-buffer behavior for existing benchmark runs.
- Record enough metadata in JSON/report output to distinguish shared-payload runs from earlier distinct-payload runs.

## Intended changes

- Add a zero-default `--submit-occupancy-shared-payload` option for Experiment 1 memmove runs.
- When enabled, point all memmove descriptors at one source/destination payload buffer while keeping per-descriptor completion records distinct.
- Run focused hardware sweeps with 10 iterations for all requested payload sizes.

## Verification

Run `cargo fmt`, targeted config/report/CLI tests, release build, and hardware runs through `launch`. Record the results under `docs/report/benchmarking/` and raw JSON under `hw-eval/results/`.

## Completion notes

Implemented `--submit-occupancy-shared-payload` for Experiment 1 memmove rows and added drain-sentinel status fields so very large dedicated-WQ bursts can be recorded as incomplete instead of panicking. The runner stops a row after the first incomplete drain to avoid reusing device-visible buffers.

Ran the requested payload-size sweep with K up to 320, gaps `0,1,10,25,50,100,150,200,300`, and requested iteration count 10. `noop`, 1 MiB, and 10 MiB rows collected 10 samples; 100 MiB and 1 GiB rows stopped after one incomplete-drain sample per row. Results are in `docs/report/benchmarking/046.submit_occupancy_payload_size_sweep_iter10.md`.

Follow-up: added explicit `hardware_observed` counts to Experiment 1 trace outcomes and reran the sweep with 4 KiB and 64 KiB payloads included. Updated results are in `docs/report/benchmarking/049.submit_occupancy_payload_observed_sweep_iter10.md`.
