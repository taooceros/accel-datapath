# Submit occupancy prefill completion timing plan

## Goal

Record, for Experiment 1, how long the K prefilled DSA requests take to become completed while preserving the existing submit-occupancy measurement shape.

## Scope

- Add per-iteration timing data to the `submit_occupancy` JSON result for the prefill slice `0..K`.
- Keep the measured submit path unchanged: prefill first, then measured submit trace, then observe completions.
- Update the Experiment 1 local documentation to describe the new signal.
- Add or update contract tests that exercise the JSON shape without requiring hardware.

## Intended changes

- Extend `SubmitOccupancyResult` with a skipped-when-empty prefill-completion trace field.
- Record elapsed TSC ticks and converted nanoseconds for a companion prefill-only probe: prefill submit-loop time, total time from first prefill submit until all prefill completions are observed, and the residual post-submit wait.
- For `K = 0`, emit a zero-duration prefill completion sample.
- Preserve existing `extra_submit_trace` and `trace_outcomes` fields.
