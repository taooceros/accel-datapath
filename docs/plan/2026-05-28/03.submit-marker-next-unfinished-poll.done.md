# Submit-marker next-unfinished poll

## Goal
Refresh Experiment 2 so each poll walks to the next unfinished completion record rather than repeatedly reading the same marker record, and visualize the moving completion frontier clearly.

## Visualization design
Use three coordinated panels for one sampled iteration:
1. Submit latency by submit index.
2. Single status-read latency, colored by whether the read saw `NONE` or a visible completion.
3. The polled frontier: step lines for the last probed request and the visible prefix after each read. Thin vertical guides mark every submit index where at least one read observed a completion.

## Scope
- Same focused hardware setup: DSA noop, marker first, burst 160, poll offset 1, 1000 iterations, pinned core 0.
- Preserved aggregate compatibility while extending per-iteration sample traces with polled request indices and statuses.
- Regenerated hardware JSON, CSV, and PNG plot.
