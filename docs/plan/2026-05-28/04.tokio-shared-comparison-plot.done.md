# Tokio async/shared hw-eval comparison plot

## Goal
Visualize the existing Tokio async versus hw-eval batch-size-1 CSV comparisons so the dedicated and shared-WQ runs can be compared at a glance.

## Scope
- Inputs: `tokio_async_dedicated_vs_hw_eval_shared_batch1.csv`, `tokio_async_vs_hw_eval_shared_batch1_wq0_1.csv`, and `tokio_async_threads1_vs_hw_eval_shared_batch1_wq0_1.csv`.
- Output: one PNG plot under `docs/report/benchmarking/` plus the script used to generate it.
- Non-goal: collecting new benchmark data.

## Verification
- `python -m py_compile docs/report/benchmarking/plot_tokio_async_shared_batch1.py`
- `python docs/report/benchmarking/plot_tokio_async_shared_batch1.py`
- `read docs/report/benchmarking/tokio_async_shared_batch1_comparison.png`

## Outcome
Generated the comparison plot as `docs/report/benchmarking/tokio_async_shared_batch1_comparison.png`.
