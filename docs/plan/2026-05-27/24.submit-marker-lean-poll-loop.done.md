# Submit marker lean poll loop

## Goal
Simplify Experiment 2 active polling loop to remove measurement overhead that sits before the completion poll. The prior cumulative trace showed that bookkeeping around the measured submit/poll slices dominates the elapsed time to first observed completion.

## Intended change
The loop will submit, optionally poll the marker completion immediately, capture the poll-end TSC, and only then update trace accumulators. Per-poll latency distributions are intentionally dropped from this hot loop; cumulative poll-end timing remains the primary evidence.

## Verification
Build in release and rerun an offset-1 one-poll hardware sample. Confirm the result still has a full 160-point trace, tracked_completions = 1, and no median completion errors.

## Completion notes
The lean loop removes the nested poll measurement and moves accounting after the poll. The interval is repeated cheap iterations until completion becomes visible, not a single submit plus one poll; the latest offset-1 rerun reported a row-level marker-visible median of 1952 TSC ticks.
