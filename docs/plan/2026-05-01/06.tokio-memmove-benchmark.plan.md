# Tokio memmove benchmark plan

## Goal

Add a minimal Tokio-based benchmark binary for `idxd-rust` that measures DSA memmove throughput using the current naive async operation future.

## Scope

- Benchmark only DSA memmove.
- Use Tokio as the execution engine with bounded worker-task concurrency.
- Keep the benchmark hardware-facing and opt-in via explicit device path or `IDXD_RUST_DSA_WQ`.
- Report elapsed time, ops/s, ns/op, and GB/s.

## Non-goals

- No batching, retry policy, hardware tuning, or broad accelerator coverage.
- No claims that the benchmark isolates hardware cost; it includes Tokio task scheduling and the naive self-waking future design.
- No automatic hardware execution in normal tests.

## Verification

- Host-free compile checks for the binary.
- `--help` path should run without hardware.
- Hardware benchmark should be run through `launch` when a DSA WQ is available.
