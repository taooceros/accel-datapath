# idxd-rust / idxd-sys boundary cleanup plan

## Goal

Make `idxd-sys` a raw bindgen/UAPI crate and move Rust convenience/helper logic into `idxd-rust`. Keep the async DSA path working while making `idxd-rust` the typed Rust wrapper over raw sys types.

## Scope

- Remove non-raw helper functions from `idxd-sys` where they can live in `idxd-rust`.
- Add small `idxd-rust` wrapper/newtype coverage for the raw descriptor, completion, portal, and enum/constant surfaces used by current sync and async code.
- Prefer `#[repr(...)]` enums for typed operation/status/flag values instead of passing raw bindgen constants through the safe layer.
- Keep existing public behavior and benchmark/proof entry points stable unless a compile error requires a narrow rename.

## Non-goals

- No broad benchmark redesign, scheduler redesign, or hardware behavior changes.
- No new operation coverage beyond currently used DSA/IAX paths.
- No hardware verification unless explicitly requested later.

## Intended changes

1. Inventory `idxd-sys` exports and current `idxd-rust` raw usages quickly.
2. Move sys-level helper bodies into `idxd-rust` modules while leaving `idxd-sys` with bindgen types/constants and minimal device mapping primitives.
3. Introduce typed wrappers/enums in `idxd-rust` and update async/sync code to consume them.
4. Run narrow formatting and package tests/checks needed to catch regressions.

## Verification

Use the smallest host-free checks that falsify the boundary cleanup:

```bash
cargo fmt --all --check
cargo test --manifest-path ./Cargo.toml -p idxd-rust --lib -- --nocapture
cargo test --manifest-path ./Cargo.toml -p idxd-sys --lib -- --nocapture
```

Completion notes will be added after implementation.

## Completion notes

Implemented the redesign as a synchronous-only cleanup:

- `idxd-sys` now exposes only bindgen/UAPI and raw `WqPortal` MMIO primitives.
- `idxd-rust` owns thin raw wrappers under `src/raw.rs` plus `src/raw/`:
  - `raw/dsa_memmove.rs`
  - `raw/iax_crc64.rs`
  - `raw/work_queue.rs`
- Async/Tokio source, tests, binaries, and verifier scripts were removed from `idxd-rust`.
- Wrapper scope was kept operation-specific rather than mirroring all bindgen constants.

Host-free verification completed with the narrow checks listed below.
