## Interpretation

The second rerun still shows that mechanism baseline and overlap baseline agree closely: similar visible range, similar number of visible submit indices, ~10 ns `NONE` reads, and ~100 ns visible reads.

This rerun differs from the previous run in one important way: the strong line-position 0/1 split is not present in selected iteration 850. Both line positions are around ~100 ns. That means the every-other cacheline pattern is not stable in every sampled iteration/run. It remains a plausible mechanism, but not the whole story by itself.

The stable story across reruns is narrower:

- visible completion reads are much more expensive than `NONE` reads;
- mechanism baseline reproduces the overlap baseline trace shape;
- prefetch-1 reduces the selected-trace high tail in this rerun, but median visible latency remains near baseline.

The next analysis should compare line-position distributions across all iterations, not only one sampled trace.
