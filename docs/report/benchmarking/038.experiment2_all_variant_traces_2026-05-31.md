# Experiment 2 all-variant traces, 2026-05-31

## Commands

```text
cargo build --release -p hw-eval

launch ./target/release/hw-eval \
  --accel dsa \
  --benchmark submit-marker-overlap \
  --device /dev/dsa/wq0.0 \
  --json \
  --iterations 1000 \
  --marker-bursts 160 \
  --marker-positions first \
  --marker-poll-offsets 1 \
  --dsa-op noop \
  --pin-core 0

launch ./target/release/hw-eval \
  --accel dsa \
  --benchmark submit-marker-mechanism \
  --device /dev/dsa/wq0.0 \
  --json \
  --iterations 1000 \
  --marker-bursts 160 \
  --marker-poll-offsets 1 \
  --dsa-op noop \
  --pin-core 0
```

The mechanism selector ran the variants sequentially in one hardware invocation. Full raw JSON was kept in `/tmp`; retained artifacts are compact per-row CSV/PNG traces plus the summary JSON.

## Validation

- Release build succeeded.
- Overlap JSON emitted one `submit_marker_overlap` row.
- Mechanism JSON emitted all expected rows: `baseline/packed-32b`, `prefetch/{1,2,4}`, `measurement/batch-scan-timing`, `cache-state/{pre-touch,clflush}`, and `layout/padded-64b`.
- Every plotted row had 1000 per-iteration traces and the selected trace had 160 points.
- Completion medians were clean for every row: completed 160, missing 0, errors 0.
- Artifact validation passed: 9 PNGs and 9 CSVs exist and every CSV has 160 rows for sample iteration 804.
