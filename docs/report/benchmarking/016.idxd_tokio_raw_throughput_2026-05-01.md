## Notes

- All rows were `claim_eligible=true` and `post_run_validation=pass`.
- With `max_page_fault_retries=8`, the 64 KiB point failed with `page_fault_retry_exhausted`; the table above uses 64 retries so the larger transfer size can complete and report throughput.
- For operation/message throughput, the best point in this sweep is around 1.1 Mops/sec at 256 B to 1 KiB messages.
