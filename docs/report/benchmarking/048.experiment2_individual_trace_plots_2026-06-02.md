# Experiment 2 individual trace plots, 2026-06-02

## Purpose

Plot one per-iteration trace for each separately-run Experiment 2 variant, with the plotted row chosen according to the variable under test rather than by a generic default.

## Variable mapping

| Family | Variable under test | Plotted row | Fixed controls |
|---|---|---|---|
| poll offset | `marker_poll_offset` | `submit_marker_overlap` | `N=160`, marker `first`, op `noop` |
| burst depth | `marker_bursts` / `N` | `submit_marker_overlap` | poll offset `1`, marker `first`, op `noop` |
| payload | `--dsa-op` / `--dsa-memmove-bytes` | `submit_marker_overlap` | `N=160`, poll offset `1`, marker `first` |
| poll-submit interval | `poll_submit_batch_n` | `submit_marker_mechanism`: baseline row for `1`, configured row for `2/4/8/16` | `N=160`, poll offset `1`, op `noop` |
| marker position | `marker_positions` | `submit_marker_overlap` | `N=160`, poll offset `1`, op `noop` |

For each row, the script selected a representative sample trace whose number of visible submit indices is closest to the median visible-submit count for that run. This avoids arbitrary random samples while still plotting a concrete iteration.
