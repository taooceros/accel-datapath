# agents AGENTS

Inherits `../AGENTS.md`.

## PURPOSE

This subtree stores durable material for coding agents: workflow reports, task-shaping notes, prompt/template rationale, and agent-operation decisions.

## PLACEMENT

- Put agent-operation plans in `plan/YYYY-MM-DD/NN.<topic>.<state>.md` only when a plan reduces risk.
- Put durable workflow reports in `report/workflow/`.
- Keep executable agent assets in their established runtime locations.
- Link historical domain docs from `../archive/docs/` instead of copying them.

## STYLE

- Keep agent plans short and actionable.
- Use topic-local report names such as `001.<descriptor>.md`.
- Use this subtree for durable guidance, not transient notes.
