# Submit marker next-unfinished poll

## Goal
Change Experiment 2 polling from repeatedly reading the marker completion to reading the current next unfinished completion record, while still measuring exactly one status-read latency per read.

## Scope
- Keep one timed completion status read per individual record access.
- Maintain a per-iteration completion frontier: start at the first unfinished request, advance for every non-NONE status, and stop at the first NONE status.
- Record the polled request indices, observed statuses, status-read latencies, and visible prefix in each per-iteration sample point.
- Update the plot to show submit latency, status-read latency colored by unfinished/finished status, and a frontier/visible-prefix panel so the moving target is understandable.
- Rerun the focused hardware experiment and regenerate JSON/CSV/PNG artifacts.
