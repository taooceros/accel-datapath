# Rust DSA page-fault retry execution plan

## Reader

Coding agents updating Rust DSA bytes codecs after observing intermittent DSA `PAGE_FAULT_NOBOF` completions in hardware benchmarks.

## Objective

Handle `DsaCompletionStatus::PageFaultNoBof` in both sync and async Rust DSA bytes codecs by touching `fault_addr`, adjusting the memmove descriptor by `bytes_completed`, clearing completion, and resubmitting until success or a bounded non-retryable failure.

## Steps

1. Inspect `idxd-rust` descriptor/completion APIs and existing C++ page-fault retry behavior.
2. Add reusable Rust retry adjustment logic local to the DSA bytes crates.
3. Wire retry into synchronous encode submission.
4. Wire retry into asynchronous pending-copy polling without changing buffer ownership or drop-drain semantics.
5. Add unit tests that do not require hardware.
6. Run focused tests, async hardware smoke through `launch`, and bytes RPC benchmark.

## Constraints

- Do not pin pages as the fix.
- Do not weaken existing successful DSA fast paths.
- Do not spin forever on repeated no-progress page faults.
- Keep tonic core free of DSA-specific behavior.
