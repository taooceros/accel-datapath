# Agent execution plans

This directory stores plan records for work whose primary purpose is agent operation rather than the domain project itself.

Use this location for plans about:

- delegation workflows and subagent task shape;
- prompt templates and reusable agent procedures;
- live-thread state, resume, handoff, and dashboard behavior;
- repo-local agent skills or agent-facing search/tooling guidance.

Keep human project plans in `../../docs/plan/` when the work primarily changes research code, hardware experiments, reports, presentations, or specifications.

Agent execution plans still need to be readable by humans: state the goal, scope, intended changes, verification, and completion notes in plain language.
