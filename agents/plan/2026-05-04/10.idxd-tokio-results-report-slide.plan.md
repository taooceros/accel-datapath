## Execution steps

1. Reuse the presentation template helpers from `presentation/template.typ`.
2. Rewrite the report as a characteristics deck from the revised human plan:
   - slide 1: comparison contract and a small number of highlights,
   - generated slides: one plot per message size from a Typst `scenarios` array and `#for` loop,
   - each generated plot sweeps all NUMA0 Tokio thread counts `1, 2, 4, 8, 16, 32, 64` at fixed `c=128`, and overlays raw NUMA0 32T/64T spot-checks,
   - dual-y plots: left `Mops/s`, right `GB/s` bandwidth,
   - no best-row matrix that mixes concurrency or message size.
3. Compile with `typst compile`.
4. If compile succeeds, run Tinymist preview and capture a screenshot through browser automation.
5. If the screenshot shows crowding or illegible text, make a minimal Typst adjustment and recompile.
6. Update completion status in the human plan only if useful and low-risk.
