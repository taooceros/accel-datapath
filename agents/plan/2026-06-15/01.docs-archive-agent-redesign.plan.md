# Docs archive and agent workflow redesign

## Goal

Move the current `docs/` knowledge base out of the active path and replace root agent guidance with an execution-first workflow that treats old reports as archive material rather than live navigation.

## Scope

- Archive the current `docs/` tree without deleting its contents.
- Rewrite root `AGENTS.md` to reduce mandatory planning/reporting overhead.
- Keep hardware terminology and RTK command guidance available.
- Do not edit code paths or historical document contents during this reset.

## Intended changes

- Move `docs/` to `archive/docs/`.
- Update active documentation conventions in `AGENTS.md` around notes, evidence, reports, and plans.
- Make plan/report writing conditional instead of automatic.

## Verification

- Check repository status after the move and rewrite.
- Verify the archived docs tree exists and active root guidance points at the new model.
