# DSA raw wrapper expansion plan

## Goal

Rename the DSA memmove-specific raw wrapper to a general DSA wrapper module and expose thin descriptor/completion helpers for the DSA opcodes present in `idxd-sys` generated UAPI.

## Scope

- Rename `idxd-rust/src/raw/dsa_memmove.rs` to `idxd-rust/src/raw/dsa.rs`.
- Update module exports from `dsa_memmove` to `dsa`.
- Keep `idxd-rust` as simple wrappers only: descriptor/completion/newtype/enums and field fill/access helpers.
- Add DSA opcode/status/flag coverage based on generated `idxd_uapi` constants.
- Add operation fill helpers where descriptor fields are clear from the generated UAPI layout.

## Non-goals

- No sessions, lifecycles, retry policy, validation policy, async code, or hardware-facing verifier code.
- No speculative high-level API design.
- No hardware behavior claims.

## Verification

Narrow host-free checks only:

```bash
cargo test --manifest-path ./Cargo.toml -p idxd-rust --lib --tests --quiet
cargo fmt --all --check
```
