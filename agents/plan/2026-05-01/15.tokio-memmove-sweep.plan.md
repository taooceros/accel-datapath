# Tokio memmove sweep plan

## Goal

Add a simple experiment runner for the Tokio memmove benchmark that sweeps message size and concurrency.

## Scope

- Direct descriptor submission only: no DSA `BATCH` descriptor.
- Treat every operation as `batch_n=1` in experiment metadata.
- Loop over configurable message sizes and concurrency levels.
- Build the release binary once, then run it through `launch` for hardware access.
- Write JSONL output for later analysis.

## Verification

- Host-free shell syntax check.
- `tokio_memmove_bench --help` still works.
