# DSA Rusty wrapper API plan

## Goal

Add ergonomic Rust-facing descriptor fill helpers on top of the current raw pointer helpers.

## Scope

- Keep existing raw `fill_*` pointer methods.
- Add slice/reference methods in each operation module that call the raw fill method.
- Do not add lifecycle, validation, retries, sessions, or safety policy.
- Treat lengths mechanically from Rust slices; this is convenience over raw descriptor filling only.

## Verification

- Add host-free tests that cover all Rusty helper methods by checking descriptor fields.
- Run `cargo test --manifest-path ./Cargo.toml -p idxd-rust --tests --quiet` and `cargo fmt --all --check`.
