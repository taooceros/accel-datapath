# Tokio memmove benchmark implementation plan

## Goal

Implement a simple Tokio runtime benchmark binary for `idxd-rust` DSA memmove futures.

## Steps

1. Add Tokio runtime dependency to `idxd-rust`.
2. Add `src/bin/tokio_memmove_bench.rs`.
3. Parse simple CLI options: device, total bytes, message size, concurrency, runtime threads, verify, json.
4. Build a multi-thread Tokio runtime and spawn `concurrency` worker tasks.
5. Each worker repeatedly awaits `DsaEngine::memmove` and reports operation count.
6. Print throughput metrics.

## Verification

Run narrow host-free commands:

```bash
cargo check --manifest-path ./Cargo.toml -p idxd-rust --lib --bins --tests
cargo test --manifest-path ./Cargo.toml -p idxd-rust --tests --quiet
cargo run --manifest-path ./Cargo.toml -p idxd-rust --bin tokio_memmove_bench -- --help
cargo fmt --all --check
```
