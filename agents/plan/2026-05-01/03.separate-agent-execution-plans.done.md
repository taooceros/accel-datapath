# Separate agent execution plans from human project plans

## Goal

Make `docs/plan/` the home for human-readable project work plans, and move plan records whose primary purpose is agent execution/workflow/tooling into the new top-level `agents/` area.

## Scope

- Add an `agents/plan/` convention for agent execution plans and agent-workflow/tooling plan records.
- Move a bounded set of clearly agent-focused historical plans out of `docs/plan/`.
- Keep domain implementation, research, presentation, benchmark, and hardware plans in `docs/plan/`.
- Update active placement guidance so new agent execution plans do not go into `docs/plan/`.
