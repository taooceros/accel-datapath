# Naive async binding plan

## Goal

Add the smallest async binding over the raw DSA wrapper: an engine owns the portal and work-queue mode; an operation future submits its descriptor once, then each `poll` checks the completion record.

## Scope

- No Tokio/runtime dependency.
- Use `std::future::Future` only.
- No background thread, interrupts, eventfd, or waker integration beyond immediate re-wake.
- No retry, validation, cancellation cleanup, or safety policy.
- Expose generic descriptor submission plus a few convenience constructors that fill descriptors from Rust slices.

## Verification

- Host-free compile/tests only for API shape.
- Hardware behavior remains covered by the existing opt-in hardware test path when a DSA WQ is provided.
