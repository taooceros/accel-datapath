# async module rename plan

## Goal

Rename the naive async binding module to the accelerator-neutral module `idxd_async`.

## Scope

- Move `idxd-rust/src/dsa_async.rs` to `idxd-rust/src/idxd_async.rs`.
- Use `pub mod idxd_async;` in `lib.rs`.
- Keep root re-exports for `DsaEngine` and `DsaOperation`.
- Add a small contract that the module path works.

## Verification

- `cargo check --manifest-path ./Cargo.toml -p idxd-rust --lib --tests`
- `cargo test --manifest-path ./Cargo.toml -p idxd-rust --tests --quiet`
- `cargo fmt --all --check`
