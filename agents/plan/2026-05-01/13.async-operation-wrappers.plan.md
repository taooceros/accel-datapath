# async operation wrappers plan

## Goal

Expose async future constructors for each DSA descriptor operation, matching the Rusty descriptor API.

## Scope

- Keep the naive future lifecycle unchanged: submit on first poll, poll completion after.
- Add `DsaEngine` methods for every DSA operation wrapper.
- Return `DsaOperation` futures that borrow the relevant buffers/descriptors.
- No validation, runtime integration, retry, cancellation, or safety policy.

## Verification

- Host-free type/contract tests for the async constructor surface.
- Existing hardware-gated async test remains opt-in.
- Run narrow cargo check/test/fmt.
