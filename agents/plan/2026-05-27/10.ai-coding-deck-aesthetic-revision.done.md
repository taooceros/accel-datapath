## Reader and scope

This execution plan covers restyling the drafted Anthropic coding-skill discussion deck after the user rejected the current look as insufficiently artistic and aesthetic.

## Inputs

- User feedback that the current slide style is too far from artistic/aesthetic.
- Updated human plan aesthetic revision guidance in `docs/plan/2026-05-27/04.ai-coding-skill-formation-discussion.done.md`.
- Existing deck and notes under `presentation/2026-05-27/`.

## Work plan

1. Replace the box-heavy template style with a custom editorial visual system:
   - warm paper background;
   - deep navy typography;
   - muted coral, amber, blue, and green accents;
   - large type and generous whitespace;
   - section divider slides;
   - repeated artifact-path versus learning-path motif.
2. Preserve the deck's claims, caveats, discussion prompts, bibliography, and presenter notes.
3. Compile the Typst deck to PDF.
4. Export PNG previews and inspect representative slides.
5. Read the generated PDF text to confirm title, result, personas, discussion prompts, and bibliography remain present.
6. Rename this execution plan to `.done.md` after verification succeeds.

## Verification standard

- Typst PDF compile succeeds.
- PNG preview export succeeds.
- Representative PNG previews show the revised visual language.
- PDF text extraction confirms all key sections remain present.
