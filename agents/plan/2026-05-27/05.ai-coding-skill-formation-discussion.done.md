# Agent execution plan: HAI coding skill formation discussion deck

## Reader and scope

This is an execution plan for producing a course discussion slide deck under `presentation/2026-05-27/` based on Anthropic's coding skill-formation article and paper.

## Inputs

- User request for a CSE 599H course participation presentation.
- `presentation/AGENTS.md` slide-plan and compilation requirements.
- Primary article and arXiv paper fetched in-session.
- Context sources fetched in-session: Peng et al. 2023, Becker et al. 2025, Anthropic productivity estimates, Lee et al. 2025.

## Work plan

1. Create a human-readable slide plan in `docs/plan/2026-05-27/04.ai-coding-skill-formation-discussion.active.md` with goal, sources, story spine, slide-by-slide components, and delivery guidance.
2. Create a Typst deck in `presentation/2026-05-27/ai_coding_skill_formation_discussion.typ` using the existing presentation template.
3. Include speaker notes through Touying `speaker-note` metadata and generate a `.pdfpc` sidecar; also write a markdown fallback notes file.
4. Compile the final PDF.
5. Verify by compiling, querying notes, and extracting PDF text to check that the deck includes the expected slide titles and bibliography.
6. Rename both plans from `.active.md` to `.done.md` after successful verification.

## Verification standard

- `typst compile --root presentation presentation/2026-05-27/ai_coding_skill_formation_discussion.typ presentation/2026-05-27/ai_coding_skill_formation_discussion.pdf` succeeds.
- `typst query --root presentation presentation/2026-05-27/ai_coding_skill_formation_discussion.typ --field value --one '<pdfpc-file>'` succeeds and writes `.pdfpc` with notes.
- Reading the generated PDF confirms slide titles and bibliography text are present.

## Non-goals

- Do not conduct a full literature review beyond the context needed for the discussion deck.
- Do not introduce a new slide framework.
- Do not make claims about long-term retention beyond the paper's immediate quiz evidence.
