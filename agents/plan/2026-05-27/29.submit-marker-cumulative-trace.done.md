# Submit marker cumulative trace

## Goal
Add cumulative TSC fields to Experiment 2 trace points so the offset-1 result can explain why first marker visibility takes about 1174 ticks even though individual submit/poll slices are small.

## Scope
- Record submit start, submit end, and poll end offsets from marker submit start for each trace point where the marker submit has happened.
- Keep existing per-slice submit and poll latency stats.
- Rerun the one-completion offset-1 hardware sample and compute a contribution table.

## Verification
Run targeted unit tests, release build, hardware rerun, and JSON checks for cumulative fields.
