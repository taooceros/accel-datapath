# Submit occupancy TSC gap execution plan

## Goal

Implement and validate a TSC-tick inter-submit pacing knob for Experiment 1.

## Scope

- Work in `hw-eval` config, Experiment 1 runner, result metadata, docs, and focused tests.
- Keep the prior black-box iteration option available but make the new TSC-tick knob the measured pacing path.
- Do not run hardware binaries directly; use `launch` for focused measurements.

## Steps

1. Add `submit_occupancy_gap_tsc` config and CLI plumbing.
2. Introduce an explicit gap helper that applies TSC waits first, otherwise legacy black-box loop iterations.
3. Record `gap_tsc_ticks` in Experiment 1 result rows and output.
4. Update tests/docs and run cargo fmt/check/build plus cargo asm.
5. Run focused hardware rows and write a short benchmarking report.

## Verification

Use targeted unit/contract tests, `rtk cargo build --release -p hw-eval`, `rtk cargo asm`, and focused `launch` runs on `/dev/dsa/wq0.0`.
