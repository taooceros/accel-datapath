# Agent execution plan: hw-eval submit-only baseline

## Goal

Implement a narrow DSA submit-only microbenchmark in `hw-eval` without changing existing benchmark rows.

## Scope

Files expected to change:

- `hw-eval/src/methodology/dsa.rs`
- possibly `hw-eval/tests/cli_contract.rs` if JSON/CLI contract tests require updates

## Steps

1. Inspect existing DSA methodology helpers and report shape.
2. Add a helper that prebuilds a NOOP descriptor, repeatedly submits it in a timed burst, drains outside the timed region, and pushes a throughput result.
3. Wire the helper into `run_dsa_benchmarks` once per DSA run, independent of payload sizes.
4. Run targeted host-side verification that does not require hardware.

## Acceptance

- Existing JSON schema remains valid.
- New row is clearly named as submit-only/repeated-same-descriptor.
- Timed region excludes descriptor fill and completion polling.
- Hardware commands are not run directly.
