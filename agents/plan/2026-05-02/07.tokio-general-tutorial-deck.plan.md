# Agent plan: Tokio general tutorial deck

## Task

Create a prototype Typst slide deck that teaches Tokio/Rust async generally, without hardware integration and without `stdexec` slides.

## Steps

1. Use `docs/plan/2026-05-02/06.tokio-general-tutorial-deck.plan.md` as the slide design contract.
2. Create `presentation/2026-05-02/tokio_general_tutorial.typ` using the existing presentation template.
3. Keep the visual style simple and tutorial-oriented: diagrams, pseudo-code, and compact takeaways.
4. Make the lifetime challenge prominent, especially `spawn` requiring owned/`'static` data and `Send` for multi-threaded scheduling.
5. Compile the deck.
6. Use Tinymist live preview and browser screenshots for layout iteration.
7. Update completion notes after verification.

## Constraints

- Do not include `stdexec` in this prototype.
- Avoid DSA/IAX hardware-specific examples.
- Do not make performance claims.
- Prefer clear teaching slides over dense reference material.
