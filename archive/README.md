# Archive

Historical material lives here so the repository root stays small.

## Contents

- `docs/` — former active docs tree: plans, reports, specs, related work, and design records.
- `root/report/` — old root-level reports.
- `root/results/` — old root-level benchmark result CSVs.
- `root/benchmark_plots/` — old generated plots.
- `root/debug_reports/` — old debug report artifacts.
- `root/papers/` — old local paper/PDF staging material.
- `root/dsa_benchmark_results.csv` and `root/hw_test_results.csv` — old root-level result files.

Use archived material as reference. Curate current conclusions into `../docs/evidence/` when a research thread needs a stable entry point.
