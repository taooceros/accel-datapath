# Customized integration benchmark report graphics

## Goal
Improve the customized integration Criterion report so the main benchmark results are easier to scan and include plots for single-worker, DSA concurrency, and thread-matrix comparisons.

- Existing Criterion artifacts under `accel-rpc/tonic/target/criterion`.
