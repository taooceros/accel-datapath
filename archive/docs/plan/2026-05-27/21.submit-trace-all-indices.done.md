# Submit trace all indices

## Goal
Experiment 2 should separate submit timing from poll timing. Submit latency must be recorded for every descriptor index, even when completion polling starts later via `marker_poll_offset`.

## Intended change
The benchmark will keep one trace point per submit index from 1 through N. Each trace point will always contain submit timing. Completion visibility and poll-latency statistics will be populated only for indices at or after the polling offset, where polling actually occurred.

## Verification
Run formatting, targeted contract/config tests, release build, then rerun a small-offset hardware sample and confirm trace length equals N for every offset.

## Completion notes
The benchmark now emits a full submit-index trace for Experiment 2 regardless of polling offset. Pre-offset points carry submit timing and `poll_performed: false`; polled points carry submit timing plus completion poll statistics. The rerun for offsets 1, 32, and 64 produced 160 trace points for each row.
