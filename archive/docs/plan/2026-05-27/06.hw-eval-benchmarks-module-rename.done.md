# hw-eval benchmark module rename plan

## Goal
Rename the internal `methodology` module to a clearer name that matches what the code contains: executable benchmark suites and experiment runners for DSA, IAX, software baselines, and submission-bottleneck probes.

## Rationale
`methodology` sounded like documentation about experimental method. The module actually held runnable benchmark implementations split by benchmark family and accelerator. `benchmarks` is more direct, shorter, and still covers hardware and software baselines without pretending every submodule is a hardware device.

## Scope
- Rename `hw-eval/src/methodology.rs` to `hw-eval/src/benchmarks.rs`.
- Rename `hw-eval/src/methodology/` to `hw-eval/src/benchmarks/`.
- Update Rust module declarations and imports.
- Update README and `hw-eval/AGENTS.md` structure/discovery text.
- Preserve CLI selectors, JSON schema, benchmark behavior, and module contents other than path/name references.

## Non-goals
- Do not change benchmark semantics.
- Do not reorganize root ABI helper modules (`src/dsa.rs`, `src/iax.rs`, `src/sw.rs`).
- Do not run hardware measurements.

## Changes made
- Replaced the internal module path with `src/benchmarks.rs` plus `src/benchmarks/`.
- Updated `main.rs` imports from `methodology::*` to `benchmarks::*`.
- Changed the DSA benchmark module to import sibling submission-bottleneck dispatch through `super::submission_bottleneck`.
- Updated README and `hw-eval/AGENTS.md` so maintainers look under `src/benchmarks/` for benchmark implementations and under root `src/{dsa,iax,sw}.rs` for helper façades.
