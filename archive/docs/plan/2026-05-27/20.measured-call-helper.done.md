# Measured call helper plan

## Goal

Make the Experiment 2 trace code easier to read and maintain by centralizing the repeated `rdtscp` start/end pattern into one helper that measures a closure and returns the closure result plus timing metadata.

## Scope

- Add a helper local to the submission-bottleneck benchmark implementation.
- Use it for the traced submit call and completion-status poll in `submit-marker-overlap`.
- Do not change CLI behavior, JSON field names, or hardware semantics.
