# Submit marker all success polls

## Goal
The current Experiment 2 result records the first marker success per iteration as `marker_visible_tsc_ticks`, while the trace reports only per-index success counts/fractions. To understand the full success trajectory inside each iteration, record all successful marker polls with cumulative TSC offsets from marker submit start.

## Intended change
Each trace point will expose success-only cumulative poll-end TSC statistics. The row will also expose aggregate stats and count for all successful marker polls observed during the active polling loop. The hot loop should remain lean: successful poll timestamps are recorded after the status load and post-load TSC have already been captured.

## Verification
Use release hardware data for offset 1 and confirm every trace point has the new field, row-level success count is nonzero, and completion medians remain clean.
