# Poll window median of deltas

## Goal
The submit/poll trace plot must report the median of the per-iteration polling window, not the difference between two separately computed medians.

## Intended change
Each trace point will record `poll_window_tsc_ticks` directly from the same iteration as `poll_end_tsc - submit_end_tsc`. The plot will use this field for the polling window panel.

## Verification
Regenerate the offset-1 run and confirm the JSON contains poll-window stats for every polled trace point before plotting.

## Completion notes
The submit/poll trace plot now reports median(poll_end - submit_end) using per-iteration poll-window samples emitted by the benchmark. It no longer subtracts two independently computed medians. The offset-1 rerun validated that every trace point includes poll-window stats.
