# Presentation asset layout migration plan

## Goal

Adopt the new presentation layout across existing dated slide decks: each deck should live in its own folder, and generated preview images should live under that deck's `assets/previews/` folder rather than directly in the dated presentation directory.

## Scope

- Migrate existing decks under `presentation/YYYY-MM-DD/` into deck-local folders named after each deck stem.
- Move matching PDFs and deck-local sidecars with their deck source.
- Move generated PNG previews/snapshots into `assets/previews/` below the relevant deck folder.
- Update moved Typst sources so imports of the shared `presentation/template.typ` still resolve.
- Leave `presentation/template.typ` at the shared top level.

## Intended changes

- Use multiple task agents to investigate each date cluster and perform non-overlapping moves.
- Keep filename stems stable so old deck names remain easy to recognize.
- Preserve generated artifacts rather than regenerating them unless verification requires a compile check.

## Verification

- Compile every moved Typst entry file with `typst compile --root presentation` to a temporary output path.
- Check that no dated presentation root still contains deck `.typ`, matching `.pdf`, or generated `.png` artifacts.
- Review git status and stage only presentation-layout migration files before committing.
