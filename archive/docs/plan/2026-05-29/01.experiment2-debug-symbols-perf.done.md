# Experiment 2 debug symbols and perf profile

## Goal
Enable source-symbolized profiling for the optimized `hw-eval` binary and collect a quick perf sample for the current Experiment 2 implementation.

## Scope
- Added debug symbols to release builds while preserving release optimization.
- Profiled only `submit-marker-overlap` with DSA noop, burst 160, marker first, poll offset 0, and 5000 iterations.
- Stored perf data/report artifacts under `docs/report/benchmarking/submission_bottleneck_2026-05-27/` and summarized findings in `docs/report/benchmarking/029.experiment2_perf_debug_symbols_2026-05-29.md`.

## Verification
- Release binary has DWARF sections.
- Targeted Rust tests pass.
- Perf report generated and reviewed for codepath overhead.

## Outcome
- `target/release/hw-eval` now has DWARF debug symbols.
- Perf captured 5481 `hw-eval` samples with zero lost samples.
- Avoidable overhead is visible in per-poll/sample trace vector allocation/cloning and post-run stats sorting.
