# Sync vendored Tonic fork with upstream grpc-rust

## Goal

Update the `accel-rpc/tonic` vendored submodule and the configured fork at `https://github.com/taooceros/tonic.git` to the latest commit from upstream `https://github.com/grpc/grpc-rust`, so the DSA/Tonic integration work starts from the current upstream state.

## Scope

- Inspect the current submodule remotes and commit.
- Add/fetch the upstream `grpc/grpc-rust` remote.
- Fast-forward the fork's `master` branch to upstream `master`.
- Push the fast-forwarded branch back to the fork.
- Update the parent repository's submodule pointer and this plan record.
- Verify that the submodule checkout is clean and that the `accel-rpc` workspace still builds/checks as far as the normal workspace permits.

## Non-goals

- Do not modify vendored Tonic source in this step.
- Do not resolve unrelated existing working-tree changes.
- Do not change the `tonic` crates.io dependency used by normal workspace members unless verification shows it is required.

## Verification

- `git -C accel-rpc/tonic status --short --branch`
- `git -C accel-rpc/tonic rev-parse HEAD`
- `cargo check` from `accel-rpc`
