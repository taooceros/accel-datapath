# Neutral bytes benchmark crate

## Goal

Move the standard/sync/async bytes RPC comparison out of `tonic-dsa-bytes-async` into a neutral benchmark crate so the async DSA crate only owns async DSA functionality.

## Scope

- Target workspace: `accel-rpc/tonic`.
- New neutral crate: `tonic-bytes-bench`.
- Move the `compare_bytes_rpc_throughput` executable into the neutral crate.
- Keep `tonic-dsa-bytes-async` focused on its library and hardware smoke test.
- Preserve the benchmark command semantics and report results.

## Intended changes

- Add `tonic-bytes-bench` to the workspace.
- Move the comparison binary source from `tonic-dsa-bytes-async/src/bin` to `tonic-bytes-bench/src/bin`.
- Transfer benchmark-only dependencies from `tonic-dsa-bytes-async` to `tonic-bytes-bench`.
- Update benchmark reports/plans to point at the neutral crate.

## Verification plan

- Format affected crates.
- Check, test, clippy, and release-build the neutral benchmark crate.
- Re-check the async DSA crate to ensure dependency trimming did not break it.
- Run a short hardware comparison through `launch` from the repository root.

## Completed changes

- Added `accel-rpc/tonic/tonic-bytes-bench` and registered it in the `accel-rpc/tonic` workspace.
- Moved `compare_bytes_rpc_throughput.rs` from `tonic-dsa-bytes-async/src/bin` to `tonic-bytes-bench/src/bin`.
- Trimmed benchmark-only dependencies from `tonic-dsa-bytes-async`; it now keeps only its library dependencies plus test-only `http-body` and `tokio-stream`.
- Updated the comparison report and prior completion notes to reference `tonic-bytes-bench`.
