# Experiment 2 rerun, 2026-06-02

## Method

Built the release `hw-eval` binary and ran the documented focused Experiment 2 default suite on `/dev/dsa/wq0.0`, pinned to core 0:

```text
launch ./target/release/hw-eval \
  --accel dsa \
  --benchmark submit-marker-overlap \
  --device /dev/dsa/wq0.0 \
  --json \
  --iterations 1000 \
  --marker-bursts 160 \
  --marker-positions first \
  --marker-poll-offsets 1 \
  --dsa-op noop \
  --pin-core 0
```

The launcher prepended its `Running:` line to stdout, so the captured raw stream was preserved and the cleaned JSON artifact starts at the JSON object.

Artifacts:

- Clean JSON: `docs/report/benchmarking/submission_bottleneck_2026-06-02/experiment2_submit_marker_overlap_noop_iter1000_offset1.json`
- Raw launcher output: `docs/report/benchmarking/submission_bottleneck_2026-06-02/experiment2_submit_marker_overlap_noop_iter1000_offset1.raw`
