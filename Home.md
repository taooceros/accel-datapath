# Tonic DSA knowledge vault

Open this repository root as the Obsidian vault. The vault keeps the existing project paths intact so code, plans, reports, and agent guidance continue to use their repository-native locations.

## Start here

- [[docs/README|Project docs map]] — research plans, reports, specs, and related work.
- [[agents/README|Agent operating materials]] — agent-facing plans, workflow reports, and coding requirements.
- [[remark/README|Research remarks]] — single-point insights distilled from experiments and reviews.
- [[docs/research_plan|Research plan]] — thesis-level narrative for the batching regime change.

## Vault rules

- Keep domain research and validation under `docs/`.
- Keep agent operating material under `agents/`.
- Keep short durable observations under `remark/`.
- Prefer normal relative markdown links for files that may be read outside Obsidian; use wiki links in navigation pages only.
