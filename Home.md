# Tonic DSA knowledge vault

Open this repository root as the Obsidian vault. The vault now separates active working state from archived historical docs.

## Start here

- [[AGENTS|Project operating rules]] — active workflow, evidence discipline, and repo map.
- [[agents/README|Agent operating materials]] — agent-facing workflow material when explicitly needed.
- [[remark/README|Research remarks]] — single-point insights distilled from experiments and reviews.
- `archive/docs/` — historical plans, reports, specs, related work, and the former docs map.

## Vault rules

- Keep current state in `notes/now.md` when needed, not in plans.
- Keep current research conclusions in `docs/evidence/` only when deliberately rebuilding a thread map.
- Keep historical records under `archive/` unless actively curating them into current evidence.
- Keep agent operating material under `agents/`.
- Keep short durable observations under `remark/`.
- Prefer normal relative markdown links for files that may be read outside Obsidian; use wiki links in navigation pages only.
